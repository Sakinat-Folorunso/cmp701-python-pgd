# Course alignment – CMP 701

## Learning outcomes → where they are practised

| # | Outcome (from the course outline) | Practised in |
|---|---|---|
| 1 | Explain fundamental concepts of programming and computational thinking | Weeks 1–2 |
| 2 | Design algorithms and flowcharts for real-world problems | Week 2 (ATM algorithm + flowchart), mini-project design step |
| 3 | Write, test and debug well-structured programs | Weeks 3–12; Week 13 (debugging, `assert` tests) |
| 4 | Apply decision-making and iterative control structures | Weeks 5–7 |
| 5 | Use basic data structures: lists, dictionaries, files | Weeks 8, 9, 12 |
| 6 | Develop modular programs using functions and introductory OOP | Week 10 (functions), Week 14 (classes) |
| 7 | Demonstrate good practice, documentation and ethical use of code | Docstrings (Week 10), tests (Week 13), AI-assistance declaration and integrity statement (mini-project) |

## Week-by-week map

| Week | Notebook | Assignment to set |
|---|---|---|
| 1 | `Week01` | Print five real-life problems solvable by programs (notebook); optional one-page essay on programming in one domain |
| 2 | `Week02` | Algorithm **and flowchart** for an ATM withdrawal (PIN limit of 3 attempts) |
| 3 | `Week03` | Program collecting name, matric number and three scores; display the average |
| 4 | `Week04` | Net salary from basic pay and deductions (pass/fail program is the class task) |
| 5 | `Week05` | Loan eligibility with age, income and employment status (electricity bill is the class task, flat and marginal versions) |
| 6 | `Week06` | Sum numbers until the user enters 0 |
| 7 | `Week07` | Multiplication tables 1–5 with nested loops (even numbers up to 50 is the class task) |
| 8 | `Week08` | Names and scores of 10 students as `(name, score)` tuples; highest, lowest, sorted listing |
| 9 | `Week09` | Student records as dictionaries; highest scorer |
| 10 | `Week10` | Modular student-record program with 4+ documented functions |
| 11 | `Week11` | Sentence analyser (characters, words, upper/lower case) |
| 12 | `Week12` | Store names and scores in a CSV file; read it back; show highest score; handle a missing file |
| 13 | `Week13` | Error-tolerant calculator with at least five `assert` tests |
| 14 | `Week14` + mini-project workbook | Mini-project (Options A/B/C) with design note, sample runs and AI declaration |

## Assessment structure (to confirm in the course outline)

The outline lists continuous assessment (30%) as *three class tests, take-home assignments and group work*, and one
mid-semester test (Week 7). A possible allocation that fits all three components:

| Component | Suggested marks |
|---|---|
| Class tests (Weeks 4, 7, 11) | 3 × 5 = 15 |
| Weekly assignments (best 8 of 13, auto-checked or spot-marked) | 5 |
| Group work (Week 9 or 10 pair-programming task) | 3 |
| Mini-project (rescaled from 30) | 7 |
| **Total CA** | **30** |

This is a proposal, not a decision — adjust to departmental regulations.
